# 📧 Spam Detector Model

![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)
![Machine Learning](https://img.shields.io/badge/Machine%20Learning-Logistic%20Regression-orange.svg)
![Accuracy](https://img.shields.io/badge/Accuracy-96%25-brightgreen.svg)

A Machine Learning project that classifies emails and text messages as either **Spam** or **Ham (Valid)**. Built using a Logistic Regression algorithm, this model has been trained and evaluated to achieve an impressive **96% accuracy**.

---

## 📁 Project Structure

* **`train.py`**: The machine learning script. It loads the dataset, processes the text, trains the Logistic Regression model, and saves the trained model/vectorizer.
* **`app.py`**: The main application script that loads the saved model and allows users to input new messages to check if they are spam.
* **`spam.csv`**: The dataset containing labeled text messages used to train the model.
* **`requirements.txt`**: A list of all Python libraries and dependencies required to run this project.
* **`Procfile.txt`**: Configuration file used for deploying the application to cloud platforms (like Heroku or Render).

---

## 🛠️ Technologies Used

* **Language:** Python
* **Data Manipulation:** Pandas
* **Machine Learning:** Scikit-Learn (`LogisticRegression`, `TfidfVectorizer`)
* **Model Serialization:** Joblib
